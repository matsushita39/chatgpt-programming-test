# chatgpt-programming-test

このリポジトリは、ChatGPTとGitHubを使って安全に開発する練習用プロジェクトです。

## 目的

プログラミング初心者でも、ChatGPTに日本語で指示しながら、GitHub上で次の流れを練習します。

1. mainから作業用branchを作る
2. ファイルを変更する
3. commitする
4. Pull Requestを作る
5. 内容を確認する
6. mainへmergeする

## 開発ルール

- mainを直接変更しない
- 作業するときはbranchを作る
- 変更したらcommitする
- mainへ入れる前にPull Requestで確認する
- パスワードやAPIキーは書かない

## AIへの引き継ぎ

次のChatGPTは、まずこのREADMEを読んでください。

このプロジェクトでは、GitHubを長期記憶として使います。
過去の会話やChatGPTのメモリに頼らず、README、docs、branch、Pull Request、commit履歴から現状を確認してください。
